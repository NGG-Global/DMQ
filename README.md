# המצפן האישי

כלי web עברי (RTL) לסיכום אישי של מנהלים, חלק מפעילות הסיכום של מפגש 2 —
"הטייס האוטומטי" — בתכנית **מנהיגות בתנועה · מאיצים קדימה**.

**לקוח:** דלק מוטורס · **ספק:** NGG

המשתמש נכנס דרך סריקת QR מהטלפון, ממלא שאלון קצר (עד 5 דקות) ומוריד בסיום
קובץ סיכום אישי מעוצב כ-PDF וכ-PNG.

## סטאק טכני

- **React + Vite + TypeScript**
- **Tailwind CSS** עם פלטת המותג
- פונט **Heebo** (Google Fonts), משקלים 400/600/700
- ייצוא בצד הלקוח בלבד: **html2canvas** + **jsPDF**
- ללא backend, ללא בסיס נתונים, ללא התחברות — כל המצב בזיכרון הסשן
- Mobile-first, RTL מלא (`<html dir="rtl" lang="he">`)

## הרצה מקומית

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לפרודקשן (tsc + vite build)
npm run preview  # תצוגה מקדימה של ה-build
```

## ארכיטקטורת RTL בייצוא (הסיכון הטכני המרכזי)

עברית ב-PDF נוטה להתהפך כשמציירים טקסט ישירות דרך jsPDF. כדי לעקוף זאת,
מסמך הסיכום מרונדר כ-DOM עברי תקין ונלכד כתמונה באמצעות `html2canvas`
(שמשמר במדויק את רינדור הדפדפן), ואז התמונה מוטמעת בעמוד A4 של jsPDF.
לפני הלכידה אנו ממתינים לטעינה מלאה של פונט Heebo (`document.fonts.ready`)
כדי להבטיח רינדור עקבי. כך ה-RTL והעברית נשמרים במלואם, ללא היפוך תווים.

ראו `src/utils/export.ts`.

## מבנה

```
src/
  data/questions.ts        מבנה השאלון — הניסוחים מועתקים מילה במילה מהאפיון
  components/
    EntryScreen.tsx        מסך כניסה (רקע נייבי, שם אופציונלי)
    Questionnaire.tsx      6 שדות במסך מתגלל אחד
    QuestionFields.tsx     רכיבי בחירה מרובה + טקסט חופשי
    CompassDocument.tsx    מסמך הסיכום A4 (מקור הייצוא)
    Summary.tsx            תצוגה מקדימה + כפתורי הורדה
    Logos.tsx              סמלי NGG + דלק מוטורס
    Decor.tsx              קו הדגשה מג'נטה + מוטיב משולשים
  utils/export.ts          ייצוא PDF/PNG
```

## הערות

- **לוגואים:** הסמלים ב-`Logos.tsx` הם placeholders טקסטואליים. יש להחליפם
  בקבצי הלוגו הרשמיים של NGG ושל דלק מוטורס כשיתקבלו מתיקיית הנכסים.
- שדות "אחר" חסומים ל-50 תווים; שדות הטקסט החופשי במגבלות התווים שבאפיון.
  אף שדה אינו חוסם הורדה.
